# Resume / Candidate Screening System

## Objective
Automatically rank resumes based on job requirements using Machine Learning.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Google Colab

## Features
- Resume text processing
- Skill matching
- Candidate ranking
- Match score calculation

## Project Description
This project compares candidate resumes with a job description and ranks candidates according to how closely their skills match the required skills.
